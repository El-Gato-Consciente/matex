# 3 · Matemática en LaTeX

> **Estado:** ✅ **listo** (`matematica.tex` → `matematica.pdf`) ·
> **Nivel 2 (Capacidades)** · `article` · [suite](../README.md)

Escribir matemática **desde cero pero exhaustivo**: modos, símbolos, alfabetos,
operadores, cálculo, delimitadores, matrices, alineación, decoraciones, color y
tachado, diagramas conmutativos, teoremas/lemas/definiciones, `siunitx`, un
ejemplo completo y errores comunes. Es el **molde** de la suite.

**Compilar:** `latexmk -pdf matematica.tex`.
