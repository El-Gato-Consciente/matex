# Masterclass de LaTeX (presentación)

> **Estado:** ✅ **listo** (`masterclass-latex.tex`, 44 pp) ·
> **Nivel 1 (Empezar)** · clase `beamer` · [suite](../README.md)

Una **recorrida por LaTeX** pensada como **clase/charla** (masterclass): va de lo
básico a lo intermedio, lo avanzado y ejemplos integrados, con el objetivo de
**desbloquear** a quien nunca usó LaTeX (o lo usó muy por arriba).

**Importante:** es una presentación *sobre LaTeX en general* (su formato beamer
es incidental). **No** es el documento sobre la clase Beamer — eso es el
[doc 7 · Beamer](../7-beamer/), que trabaja esa clase a fondo.

**Archivos:** `masterclass-latex.tex` + `ejemplo_*.tex` (insumos de
`\lstinputlisting`).

**Compilar:** `latexmk -pdf masterclass-latex.tex`.
